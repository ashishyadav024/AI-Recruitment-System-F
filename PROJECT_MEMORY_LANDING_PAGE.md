# AI Recruitment System - Landing Page Checkpoint

## Checkpoint Date
2026-09-25

## Current Product Stage
Landing page design is considered complete enough to move to the candidate dashboard.

## Landing Page Design Direction
- Cream / warm editorial background, not dark/light theme switching.
- Editorial serif headline typography for the main hero.
- Compact monospace / technical typography for camera telemetry and instrumentation labels.
- Blue accent color with restrained charcoal/cream supporting colors.
- Premium editorial + professional camera/optical-instrument visual language.
- No generic AI SaaS, neon cyberpunk, or dashboard-heavy landing-page styling.

## Hero Visual
The landing page uses a large camera installation as the main visual story.

Intended behavior:
- Camera is a background visual behind the content.
- Content and typography always remain readable above the camera.
- Camera deconstructs progressively with page scrolling.
- Camera should remain visible during the main scroll journey rather than being clipped by the lower panel.
- Camera shadow should remain subtle/light enough for the cream background.
- Camera should complete roughly 60% of its deconstruction during the main landing-page visual journey.

## Camera Telemetry / Atmosphere
Small technical labels are used around the camera, inspired by professional optical equipment:
- REC
- FPS
- F/1.4
- ISO
- FOCUS
- EXPOSURE
- SENSOR ACTIVE
- FRAME
- TELEMETRY
- CALIBRATION
- SIGNAL
- AUDIO
- OPTICAL STATUS

Telemetry should have visible but controlled irregular flicker. The whole website must not flicker.

## Hero Typography Effect
The headline remains editorial serif typography.

The word `Beyond` in:
`AI recruitment that thinks Beyond the resume.`
should have a visible, subtle digital flicker effect. The effect should use small opacity/brightness changes and extremely small jitter without becoming a distracting glitch effect.

## Logo
The supplied approved skull logo is the project logo. Do not redesign or replace it with the old Cortex Prep mascot.

## Scope Control
The landing page work must remain isolated from the rest of the application. Do not add unrelated dashboards, authentication, interview-room redesigns, settings, or backend changes while working on the landing page.

## Next Development Phase
The next planned UI task is the **Candidate Dashboard**.

Candidate Dashboard initial direction:
- Match the completed landing page's cream/editorial visual system.
- Do not reintroduce dark/light theme switching.
- Use the same typography hierarchy and technical monospace treatment.
- Candidate-specific settings and interviewer/student controls will be designed as part of the candidate experience.
- Interview functionality should remain connected to the existing backend rather than being replaced unnecessarily.
